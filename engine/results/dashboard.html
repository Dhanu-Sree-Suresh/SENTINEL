Gradient Inversion — the dramatic result

A raw FL update lets an aggregator reconstruct the exact input record (closed-form for logistic regression: x = grad_w / grad_b). DP-SGD's clipping and noise destroy this completely.

Byzantine Robustness — Model Poisoning Defense

One of four entities sends an adversarial (sign-flipped, 8× scaled) update every round, on the full 20,000+-record-per-entity dataset. Plain FedAvg has no defense; coordinate-wise robust aggregation fully recovers utility.
